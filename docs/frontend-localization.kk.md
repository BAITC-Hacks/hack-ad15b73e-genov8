# Интерфейсті тілдерге бейімдеу

[Русский](frontend-localization.md) · **Қазақша** · [English](frontend-localization.en.md)

Интерфейс орыс (әдепкі), қазақ және ағылшын тілдерін қолдайды.
«Русский / Қазақша / English» ауыстырғышы жоғарғы панельде орналасқан.
Таңдау localStorage ішінде `moneygraph.locale` кілтімен сақталады; сақтау орны қолжетімсіз болса,
тілді ауыстыру бет қайта жүктелгенге дейін жұмыс істейді.
Тілді өзгерту деректерді қайта жүктемейді және таңдалған түйінді өзгертпейді.

Интерфейс мәтіндері мен рөл атаулары
`frontend/src/lib/translations.ts` файлында орналасқан. Ағылшынша мәтін сөздік кілттерінде сақталады;
English таңдалғанда API түсіндірмелері түпнұсқада көрсетіледі.
Тіл контексті, сомалар мен пайыздарды пішімдеу және ауыстырғыш
`frontend/src/components/language-provider.tsx` файлында орналасқан.
Тіл ауысқанда құжаттың `lang` атрибуты жаңартылады; браузер қойындысының атауы — MoneyGraph.

API түсіндірмелері `frontend/src/lib/translate-evidence.ts` файлындағы
толық белгілі үлгілер бойынша аударылады. Сандық мәндер мен қорытынды шектеулері сақталады.
Backend жаңа үлгі қосса, оны осы файлға да қосу қажет:
мағынаны бұрмаламау үшін белгісіз түсіндірмелер түпнұсқада көрсетіледі.
API жауаптары мен CSV файлдары өзгертілмейді.

Репозиторийдің түбірінен тексеру (Node.js 24):

```powershell
node --test frontend/tests/localization.test.cjs
cd frontend
npm.cmd run build
```

Қолмен тексеру: backend пен frontend-ті іске қосып, тілді ауыстырыңыз, түйінді таңдаңыз,
тілді қайта ауыстырып, таңдалған түйін өзгермегеніне көз жеткізіңіз. Бетті қайта жүктеп,
тіл таңдауының сақталғанын тексеріңіз. Іздеуді, қателерді және тар экрандарды тексеріңіз.

## AI көмекші

Панель, дайын сұрақтар, тексеру атаулары және олардың параметрлері үш тілге аударылған.
Дайын сұрақ интерфейстің ағымдағы тілінде жіберіледі.
`POST /api/investigator` сұрауында `question`, `locale` (`ru`, `kk` немесе `en`)
және `selected_gid` бар. Таңдалған GID бөлек жіберіледі және сұрақ мәтінінің лимитін азайтпайды.
`locale` жібермейтін ескі клиенттер үшін ағылшын тілі сақталады.

Backend модельге әр жүгінгенде деректерге негізделу жөніндегі ортақ ережелерге тіл нұсқауын қосады.
Нұсқау идентификаторлар мен сандық фактілерді сақтай отырып, түсіндірмелер мен шектеулерді
аударуды талап етеді. Баптаудың жоқтығы, қателер, бос жауап және расталмаған GID туралы
хабарламалар да аударылған.
Нұсқаулар сөздігі: `backend/app/agent/localization.py`.

Тіл ауысқанда панель ағымдағы сұрақ пен жауапты тазартады, алдыңғы жауапты күтуді тоқтатады
және жаңа сұрақ үлгілерін көрсетеді. Бұл ақылы сұрауды автоматты түрде қайталап жібермейді.
Басқа тілде жауап алу үшін сұрақты қайта қойыңыз.

Сыртқы AI сұрауларын жібермей backend-ті тексеру:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -v
```

Тіл саясаты Responses API жүйесінің `instructions` параметрін қолданады:
https://developers.openai.com/api/docs/guides/text
