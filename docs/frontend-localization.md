# Локализация интерфейса

Интерфейс поддерживает русский (по умолчанию), казахский и английский языки.
Переключатель «Русский / Қазақша / English» находится в верхней панели.
Выбор сохраняется в localStorage под ключом moneygraph.locale; при недоступном
хранилище переключение продолжает работать до перезагрузки страницы.
Смена языка не перезагружает данные и не сбрасывает выбранный узел.

Тексты интерфейса и названия ролей находятся в
frontend/src/lib/translations.ts. Английский текст хранится в ключах словаря;
пояснения API для English показываются в оригинале.
Контекст языка, форматирование сумм и процентов, а также переключатель —
в frontend/src/components/language-provider.tsx.
Атрибут lang документа обновляется при переключении; заголовок вкладки — MoneyGraph.

Пояснения из API переводятся по полным известным шаблонам в
frontend/src/lib/translate-evidence.ts. Числовые значения и ограничения выводов
сохраняются. Если backend добавит новый шаблон, его нужно добавить в этот файл:
неизвестные пояснения показываются в оригинале, чтобы не искажать смысл.
Ответы API и CSV-файлы не изменяются.

Проверки из корня репозитория (Node.js 24):

```powershell
node --test frontend/tests/localization.test.cjs
cd frontend
npm.cmd run build
```

Ручная проверка: запустить backend и frontend, переключить язык, выбрать узел,
снова переключить язык и убедиться, что узел не изменился; перезагрузить страницу
и проверить сохранение языка. Проверить поиск, ошибки и узкие экраны.

## AI-помощник

Панель, быстрые вопросы, названия проверок и их параметров переведены на все
три языка. Готовый вопрос отправляется на текущем языке интерфейса.
Запрос POST /api/investigator содержит question, locale (ru, kk или en) и
selected_gid. Выбранный GID передаётся отдельно, не уменьшая лимит текста вопроса.
Для старых клиентов без locale сохраняется английский язык.

Backend добавляет языковую инструкцию к общим правилам достоверности при каждом
обращении к модели. Инструкция требует переводить объяснения и ограничения,
сохраняя идентификаторы и числовые факты. Сообщения об отсутствии настройки,
ошибках, пустом ответе и неподтверждённых GID также локализованы.
Справочник инструкций: backend/app/agent/localization.py.

При смене языка панель очищает текущий вопрос и ответ, отменяет ожидание старого
ответа и показывает новые подсказки. Это не запускает платный повторный запрос
автоматически. Для ответа на другом языке задайте вопрос заново.

Проверка backend без внешних AI-запросов:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -v
```

Языковая политика использует параметр instructions Responses API:
https://developers.openai.com/api/docs/guides/text
